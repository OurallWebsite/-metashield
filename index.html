What Metadata Could Be Leaking?

  • GPS latitude and longitude from photos
  • Camera make, model, lens, and exposure details

  • Custom document properties and revision metadata where detectable

  • No account required for basic use.

Security and Transparency

This is a privacy-focused MVP. It reduces metadata leakage risk, but it is not a guarantee of complete anonymity or forensic-level sanitization.

  • Validate important files with ExifTool or a professional auditor.
  • Keep backups before cleaning originals.
  • For legal, journalistic, or enterprise use, combine this tool with policy and verification.

Honest Limitations

  • Metadata removal does not make a file 100% anonymous.
  • File names, visible content, upload platform metadata, and account data can still reveal identity.
  • Some proprietary camera MakerNotes, embedded objects, or complex PDF structures may not be fully removable in the browser.
  • Digital signatures and PDF/A compliance may be affected by PDF cleaning.
  • Deep Office cleaning may affect collaboration history, comments, tracked changes, or macros.

Frequently Asked Questions

Does this tool upload my file to a server?

For supported workflows, the file is processed locally in your browser. The file content is not uploaded to a server by default. External JavaScript libraries may be loaded from a CDN, but your document or image content stays in the browser.

Does removing EXIF remove GPS location data?

Usually yes, if the photo contains GPS EXIF data. The tool shows which location-related fields were detected and marks them as removed after local cleaning for supported image formats.

Will removing metadata reduce image quality?

Metadata removal does not intentionally change visible pixels. However, browser-based image cleaning may re-encode the image, which can slightly change file size, compression, or color profile. Always keep a backup of important original files.

Can I remove metadata from PDF files?

Yes, the tool can detect and attempt to remove common PDF document properties such as title, author, subject, keywords, creator, producer, and dates. Some advanced PDF metadata, XMP data, attachments, annotations, or digital signatures may require professional sanitization.

Can I clean Word, Excel, and PowerPoint files?

Yes, for OOXML files such as DOCX, XLSX, and PPTX, the tool can clean common document properties stored in docProps/core.xml and docProps/app.xml. Comments, tracked changes, revision history, macros, and embedded objects may not be fully removed in this MVP.

Is metadata removal a guarantee of anonymity?

No. Removing metadata reduces privacy risk, but it does not guarantee complete anonymity. File names, visible content, embedded text, account metadata, upload platforms, and other artifacts may still reveal information.
